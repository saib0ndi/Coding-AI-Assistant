## 🛠️ **Installation & Setup**

### **Prerequisites**
1. **VS Code** 1.90.0 or higher
2. **Node.js** 18+ and npm
3. **Ollama** installed locally

### **Quick Start**
1. Install the extension from VS Code Marketplace
2. Install Ollama: `curl -fsSL https://ollama.ai/install.sh | sh`
3. Pull AI models: `ollama pull deepseek-coder-v2:236b`
4. Start MCP server: `npm start` in project directory
5. Press `Ctrl+Shift+M` to open AI chat
6. Try: `/dev implement a hello world function`

### **Supported Models**

## 🔧 **Configuration**

### **Extension Settings**
```json
{
  "mcp-ollama.enabled": true,
  "mcp-ollama.model": "deepseek-coder-v2:236b",
  "mcp-ollama.enableAgentCommands": true,
  "mcp-ollama.showWorkflowProgress": true,
  "mcp-ollama.enableDiffViewer": true,
  "mcp-ollama.enableIssuesPanel": true
}
```

### **Ollama Configuration**
```bash
# Install Ollama
curl -fsSL https://ollama.ai/install.sh | sh

# Pull recommended models
ollama pull deepseek-coder-v2:236b
ollama pull deepseek-r1:70b
ollama pull llama3.3:70b
```
