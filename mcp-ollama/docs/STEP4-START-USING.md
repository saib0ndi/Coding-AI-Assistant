# Step 4: Start Using Extension

## Open AI Chat

```bash
# Keyboard shortcut
Ctrl+Shift+M (Windows/Linux)
Cmd+Shift+M (Mac)
```

**Or via Command Palette:**
1. Press `Ctrl+Shift+P`
2. Type "SmartCode: Open AI Chat"
3. Press Enter

## Basic Commands

**Agent Commands:**
- `/dev` - Development assistance
- `/test` - Generate tests
- `/review` - Code review
- `/docs` - Generate documentation

**Code Actions:**
- Right-click code → "Explain Code"
- Right-click code → "Fix Code Issues"
- Right-click code → "Generate Tests"

## Quick Test

1. Open any code file
2. Select some code
3. Right-click → "Explain Code"
4. AI should respond with explanation

## Keyboard Shortcuts

- `Ctrl+Shift+M` - Open AI Chat
- `Ctrl+Shift+E` - Explain selected code
- `Ctrl+Space` - Code completion
- `Alt+]` - Next suggestion
- `Alt+[` - Previous suggestion
