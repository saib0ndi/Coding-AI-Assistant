# Step 1: Clone Repository

## Clone the MCP-Ollama Project

```bash
# Clone the repository
git clone <your-repository-url>

# Navigate to project directory
cd mcp-ollama
```

## Verify Clone

```bash
# Check project structure
ls -la

# You should see:
# - vscode-extension/
# - src/
# - Dockerfile
# - README.md
# - package.json
```
