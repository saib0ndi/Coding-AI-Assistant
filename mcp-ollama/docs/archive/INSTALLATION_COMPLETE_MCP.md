## 🆘 Troubleshooting

### **Extension Not Working?**
1. Restart VS Code
2. Check if extension is enabled in Extensions panel
3. Verify Ollama is running: `curl http://localhost:11434/api/tags`

### **No AI Responses?**
1. Check Ollama: `curl http://127.0.0.1:11434/api/tags`
2. Verify VS Code settings show: `http://127.0.0.1:11434`
3. If using a remote host, ensure network connectivity to that host

### **Commands Not Appearing?**
1. Press `Ctrl+Shift+P`
2. Type "SmartCode" to see all commands
3. Check if extension is activated
