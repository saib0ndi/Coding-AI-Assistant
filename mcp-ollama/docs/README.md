# MCP-Ollama Installation Documentation

Complete step-by-step installation guide for MCP-Ollama VSCode extension.

## Quick Installation

For users who want to get started immediately:

```bash
# 1. Clone repository
git clone <your-repo-url>
cd mcp-ollama

# 2. Install extension
cd vscode-extension
code --install-extension smartcode-aiassist-3.10.2.vsix

# 3. Start using (Ctrl+Shift+M in VSCode)
```
